# Changelog

Все значимые изменения в этом проекте будут документироваться в этом файле.

## [1.0.0] - 2024-12-06

### Добавлено
- Начальная версия приложения "Журнал оценок"
- CRUD операции для таблицы `grades`:
  - Создание новой оценки
  - Просмотр списка всех оценок
  - Редактирование существующей оценки
  - Удаление оценки с подтверждением
- Аутентификация через Spring Security
- Два пользователя: `admin` и `user`
- Валидация данных при вводе
- Индивидуальное CSS-оформление (тёмная тема)
- Адаптивный дизайн для мобильных устройств
- Начальные тестовые данные
- H2 Console для отладки
- Maven Wrapper для запуска без установки Maven
